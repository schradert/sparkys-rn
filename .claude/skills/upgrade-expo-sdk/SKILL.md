# Upgrade Expo SDK (devenv + bun)

Run `scripts/upgrade-expo.sh <target-major>`. Setup and the things that bite:

## Setup
- Managed Expo workflow: `android/`/`ios/` are generated by prebuild, so the native Android versions live in the SDK and are mirrored by hand into `devenv.nix`.
- bun is the package manager; `bun`/`expo` run inside `devenv shell` (`devenv shell -- bash -c '...'`).
- `app.config.js` spreads `app.json`; the `plugins` array lives in `app.json`.

## Steps
1. `bunx expo install expo@^<major>.0.0` then `bunx expo install --fix` — Expo manages its own dependencies; let it set the versions.
2. Clean reinstall (`rm -rf node_modules bun.lock && bun install`) to de-dupe native modules.
3. Update the `devenv.nix` Android pins to match the SDK. Source of truth: `ndkVersion` in `node_modules/react-native/gradle/libs.versions.toml`, `compileSdkVersion` in `node_modules/expo-modules-core/android/ExpoModulesCorePlugin.gradle`; buildTools is `<compileSdk>.0.0`. Re-enter `devenv shell` to realize them.
4. Validate with `bunx expo-doctor`; run `bun dev` once to regenerate typed-route types before trusting `tsc`.

## Gotchas
- Pin back any non-Expo tooling major the SDK toolchain doesn't support yet (53→56 needed `@babel/core` `^7`, `eslint` `^9`, `typescript` `~5.9`).
- New native peers may be required (`reanimated` 4 needs `react-native-worklets`).
- `expo-doctor` flags removed `app.json` keys and required config plugins — follow it.
- If `devenv update` breaks the eval: `devenv inputs add git-hooks github:cachix/git-hooks.nix --follows nixpkgs`, and keep `allowUnfree: true` in `devenv.yaml`.
